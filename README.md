# Поиск автозапчастей

Тестовое задание: поиск производителей по артикулу, затем предложений и аналогов через API.

React, Redux Toolkit / RTK Query, JavaScript, Vite и Bootstrap 5.

## Запуск

Нужен Node.js 22.12 или новее.

```sh
npm ci
cp .env.example .env.local   # затем задайте VITE_FAVORIT_API_KEY
npm run dev
```

Приложение доступно на [localhost:5173](http://127.0.0.1:5173/).
Для проверки можно использовать артикулы `01089` и `7160500039S`.

Для запросов нужен ключ API, в репозитории его нет. Укажите его в `.env.local`.
Переменные `VITE_*` доступны в браузере: приватный ключ в настоящем приложении нужно хранить на сервере.

Кнопки корзины и уведомлений — часть макета. Оформление заказа и подписка на поступление не реализованы.

## Команды

```sh
npm test                     # тесты обработки API и группировки товаров
npm run build                # сборка в dist/
npm run preview              # просмотр собранного приложения
npm run audit:dependencies   # проверка зависимостей
npm run format               # форматирование
```

Готовую сборку из `dist/` можно разместить на статическом хостинге.
